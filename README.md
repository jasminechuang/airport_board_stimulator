# 桃園國際機場即時航班看板 (純淨廣播版)

這是一個模擬桃園國際機場 FIDS（Flight Information Display System）即時航班動態資訊的網頁專案，提供簡潔、直覺的航班出發狀態檢視與即時廣播體驗。

## 專案特色

* **即時航班更新**：精確顯示出發時間、目的地、航空公司、班機編號、登機時間、登機門與即時航班狀態。
* **多樣化狀態標示**：支援準時、請辦理報到、登機中、最後提示、已起飛、改時、取消與依時等豐富狀態提示。
* **簡約介面設計**：專為清晰閱讀所打造的純淨版面，無過多雜訊干擾。

# Taoyuan International Airport Real-Time Flight Board (Clean Broadcast Edition)

A web-based simulation project of the Taoyuan International Airport FIDS (Flight Information Display System), providing a clean, intuitive, and real-time flight departure status monitoring experience.

## Features

* **Real-Time Flight Updates**: Accurately displays departure times, destinations, airlines, flight numbers, boarding times, gates, and live statuses.
* **Comprehensive Status Indicators**: Supports a wide range of status alerts including On Time, Check-in, Boarding, Final Call, Departed, Rescheduled, Canceled, and Estimated.
* **Minimalist UI Design**: Built with a clean interface layout designed for maximum readability and zero clutter.

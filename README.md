# 雲端國際機場即時航班看板 (純淨廣播版)
# Cloud International Airport Real-Time Flight Board (Clean Broadcast Edition)

這是一個模擬虛擬機場 FIDS（Flight Information Display System）即時航班動態資訊的網頁專案，提供簡潔、直覺的航班出發狀態檢視與即時廣播體驗。

A web-based simulation project of a virtual airport FIDS (Flight Information Display System), providing a clean, intuitive, and real-time flight departure status monitoring experience.

---

## 專案特色 / Features

* **即時航班更新 / Real-Time Flight Updates**：精確顯示出發時間、目的地、航空公司、班機編號、登機時間、登機門與即時航班狀態。
* **多樣化狀態標示 / Comprehensive Status Indicators**：支援準時、請辦理報到、登機中、最後提示、已起飛、改時、取消與依時等豐富狀態提示。
* **簡約介面設計 / Minimalist UI Design**：專為清晰閱讀所打造的純淨版面，無過多雜訊干擾。
